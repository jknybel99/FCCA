HTTPS Setup • Certificate Trust

Install the Root Certificate on Client Devices

Follow the steps below to trust your private Certificate Authority (CA) so browsers accept HTTPS for this system.

1) Download the Root Certificate

Click the button to download the root CA certificate from the server. If it doesn’t download, copy the URL and open it directly.

Download root-ca.crt
URL: /root-ca.crt
If you access this page on a hostname, the same path works (e.g., https://your.host/root-ca.crt).

Windows (Trusted Root Certification Authorities)

  1. Open certmgr.msc or press Win + R → run mmc.
  2. In MMC: File → Add/Remove Snap-in → Certificates → Computer account → Local computer → Finish.
  3. Navigate to Trusted Root Certification Authorities → Certificates.
  4. Right‑click → All Tasks → Import… → choose root-ca.crt.
  5. Complete the wizard. Ensure it appears under Trusted Root Certification Authorities.
  6. Restart your browser. Visit your site and verify the padlock shows Connection is secure.

For Firefox, also import under Settings → Privacy & Security → Certificates → View Certificates… → Authorities → Import.

macOS (System Keychain)

  1. Open Keychain Access.
  2. Select System keychain → Certificates.
  3. File → Import Items… → choose root-ca.crt.
  4. Double‑click the imported certificate → Trust → Always Trust (set SSL to Always Trust).
  5. Enter admin password if prompted. Restart your browser and revisit the site.

iOS (iPhone/iPad)

  1. On the device, open this page and tap Download root-ca.crt.
  2. iOS will prompt to review a profile. Go to Settings → Profile Downloaded and install it.
  3. Then go to Settings → General → About → Certificate Trust Settings and enable full trust for the root.
  4. Reopen Safari/your browser and test your site.

If you don’t see "Profile Downloaded", try opening the link in Safari.

Android

  1. Copy root-ca.crt to the device (Downloads is fine).
  2. Install via Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Select root-ca.crt and confirm. Reopen the browser and test the site.

On newer Android versions, user‑installed CAs are not trusted by apps by default; browsers like Chrome will trust for browsing.

Firefox (independent trust store)

  1. Open Firefox → Settings → Privacy & Security → Certificates → View Certificates….
  2. Authorities → Import… → select root-ca.crt.
  3. Enable "Trust this CA to identify websites" and confirm.

Verify the Connection

  • Visit your site (e.g., https://your.host). It should show a padlock.
  • Certificate viewer should show a chain Leaf → Intermediate → Root and say trusted.
  • If it says Not secure, clear HSTS/SSL state, restart the browser, and recheck hostname/SANs.

Troubleshooting

  • Wrong Hostname: Ensure your leaf certificate SANs include the exact hostnames or IPs you use.
  • HSTS Cached: Clear browser HSTS/SSL state (Chrome: chrome://net-internals/#hsts), then restart.
  • Mixed Content: Ensure all resources load via HTTPS or same origin.
  • Firefox still warns: Import the CA into Firefox’s Authorities store.
